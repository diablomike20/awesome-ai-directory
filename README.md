# Awesome AI Directory

💡 A curated collection of high-quality AI tool directories and resources for learning and development.

This list is dedicated to gathering and organizing excellent AI-related resource websites, including but not limited to:

- AI tool directories
- AI model API resources
- AI learning materials
- AI news and trend aggregators

The list is updated regularly, aiming to provide AI enthusiasts, developers, and researchers with an easy way to discover resources, while also offering a submission channel for creators of AI resource directories.

Contributions via Pull Requests (PRs) and Issues are welcome—please share any high-quality AI directories you’ve discovered or suggest improvements! ## Table of Contents
